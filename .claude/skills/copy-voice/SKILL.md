# Copy voice

Top Friends is a joke app (MySpace Top 8 energy) wrapped around a sincere
mechanism. The mechanism is real: it genuinely helps you keep up with
friends. The copy never admits that.

**Dry and funny. Never earnest.**

- State things flatly. The comedy is in the deadpan, not in the jokes.
- Never congratulate the user, never encourage them, never use an
  exclamation mark.
- No wellness vocabulary: nurture, connection, meaningful, journey,
  reach out, check in on your people.
- No emoji in product copy.
- Short. A label beats a sentence; a sentence beats two.

When a string starts to sound like it cares about the user, cut it back
until it sounds like it is merely reporting a fact.
